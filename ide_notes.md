# IDE vs CLI

## Удобно в VS Code

1. Визуальный diff — сразу видно, какие строки добавлены/удалены.
2. GitLens — показывает автора и дату изменения каждой строки.
3. Панель Source Control — все изменённые файлы под рукой.

## Удобнее в терминале

1. Массовые операции (например, `git log --oneline --all --graph`) — быстрее и гибче.
