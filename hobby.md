# Мой пет-проект

Идея: careerCoach - приложение для подготовки к собеселованиям и стажировкам. Составляет индивидуальный план подготовки для достижения поставленной цели.

Стек: NestJS, React, PostgresQL, ORM Prisma
Цель: разработать приложение, позволяющее оптимизировать процесс подготовки к трудоустройству.
